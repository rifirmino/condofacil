# Reajuste da taxa e taxas extras Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** permitir que o síndico reajuste a taxa (valor fixo ou fração ideal), edite o fundo de reserva e crie ou encerre taxas extras, com simulação, aviso aos moradores e histórico.

**Architecture:**
- **Cálculo:** a composição vira uma lista de versões com vigência mais uma lista de taxas extras. O cálculo de cada mês (`itensBase`) fica em `src/cobranca/dados.js`, porque a semente das cobranças precisa dele antes de `regras.js` na ordem da montagem.
- **Textos, simulação e alertas:** em `src/cobranca/composicao.js`.
- **Ações:** em `src/cobranca/acoes-composicao.js`. Vêm depois de `src/acoes.js`, porque publicam o comunicado.
- **Telas:** em `src/ui/composicao.js`.

**Tech Stack:** ES modules, Preact + htm, node:test, Chrome headless (verificar e e2e).

## Global Constraints

- Dinheiro em centavos; texto com `fmtReais`.
- Nomes de topo únicos entre todos os arquivos (`testes/montagem.test.mjs`); imports locais numa linha só.
- Ações puras devolvem `{ estado, notificacao?, erro?, id? }`; síndico só (`SO_SINDICO`).
- `armazenamento.js` aceita só `versao === 7`.
- Valores das cobranças semente iguais aos de hoje (A R$ 650 + fundo R$ 65 + fachada R$ 150 = R$ 865).
- Commits terminam com `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

```js
export const FRACOES_TIPO = { A: 0.029385, cobertura: 0.044304 };

export function versaoEm(fin, competencia) {
  return fin.composicao.versoes.filter((v) => v.vigencia <= competencia).sort((a, b) => a.vigencia.localeCompare(b.vigencia)).at(-1) || null;
}

export function ordinariaDe(fin, versao, unidade) {
  const u = fin.unidades[unidade];
  return versao.modo === 'fracao' ? Math.round(versao.orcamento * u.fracao) : versao.ordinaria[u.tipo];
}

export function fundoDe(fin, versao, unidade) {
  return Math.round((ordinariaDe(fin, versao, unidade) * versao.fundoPct) / 100);
}

export function mensalDe(fin, versao, unidade) {
  return ordinariaDe(fin, versao, unidade) + fundoDe(fin, versao, unidade);
}

export function fimExtra(extra) {
  return somarMes(extra.inicio, extra.parcelas - 1);
}

export function parcelaDe(extra, competencia) {
  const n = diferencaMeses(competencia, extra.inicio) + 1;
  if (n < 1 || n > extra.parcelas) return null;
  if (extra.situacao === 'encerrada' && (!extra.ultimaCompetencia || competencia > extra.ultimaCompetencia)) return null;
  return n;
}

export function valorExtraDe(fin, extra, unidade) {
  const porMes = extra.total / extra.parcelas;
  return Math.round(extra.rateio === 'fracao' ? porMes * fin.unidades[unidade].fracao : porMes / Object.keys(fin.unidades).length);
}

export function itensBase(fin, unidade, competencia) {
  const v = versaoEm(fin, competencia);
  const itens = [
    { tipo: 'ordinaria', descricao: 'Taxa ordinária', valor: ordinariaDe(fin, v, unidade) },
    { tipo: 'fundo', descricao: `Fundo de reserva (${v.fundoPct}%)`, valor: fundoDe(fin, v, unidade) },
  ];
  fin.composicao.extras.forEach((x) => {
    const p = parcelaDe(x, competencia);
    if (p) itens.push({ tipo: 'extra', descricao: `${x.descricao} (parcela ${p}/${x.parcelas})`, valor: valorExtraDe(fin, x, unidade) });
  });
  return itens;
}
```

Regras do `montarVersao` (sem ata; a ata é conferida na ação):
1. Vigência anterior à `primeiraNaoEmitida`: "A vigência deve ser a partir de {nomeMes}".
2. Fundo fora de 0 a 30: "O fundo de reserva deve ser de 0% a 30%".
3. Percentual:
   - com troca de modo: "Ao trocar o modo, informe os valores";
   - vazio, não numérico ou abaixo de −50: "Informe um percentual ou valores válidos";
   - arredonda cada valor (ou o orçamento) com `Math.round(v × (1 + pct/100))`.
4. Valores ≤ 0: o mesmo erro do item 3.
